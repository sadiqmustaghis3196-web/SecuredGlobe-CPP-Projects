# SecuredGlobe — Banking Web Demo

Responsive banking management demonstration built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern browser, or run:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000. No installation or build step is required. Google Fonts are optional; system fonts provide a fallback.

## Features

- Dashboard with account balances and transaction charts
- Customer registration, editing, and demo KYC status
- Savings and current accounts, freezing, and closure validation
- Deposits, withdrawals, and account transfers with balance validation
- Loan applications, approval, disbursement, and repayments
- Masked demo cards, branch and employee records
- Search, pagination, CSV exports, and printable receipts/reports
- Audit logs, transaction limits, and JSON backup/restore

## Demonstration scope

This repository contains the browser-based website created for SecuredGlobe. Despite the repository name, this upload is not a C++/Qt desktop application. All seeded data is fictional. Changes persist in browser localStorage only. There is no backend authentication, server-side role enforcement, shared database, or real payment processing. Do not enter real banking information.

Hosted site: https://securedglobe-banking-studio.mintypatio.chatgpt.site
